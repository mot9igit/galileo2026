User Guides

Connect any analog sensors

The number of analog sensors is almost limitless. Buttons, reed switches, circuit breakers, photosensitive diodes, thermistors and so on. Almost every device from this list can be connected to Galileosky unit. Galileosky devices can receive frequency data, voltage or count the number of received pulses.

Connect tachographs as well

Many vehicles are equipped with tachographs to comply with the law. They allow to monitor the driver schedule. Despite the number of useful functions, they cannot transfer data to the monitoring server. In such case, Galileosky units can ensure uninterrupted information transmission.

  • Mercury
  • Continental VDO
  • Atol Drive 5

Control temperature and humidity

In addition to the basic climate data, Galileosky unit allow to set up an automatic response in case of crucial parameters changes. Control air, soil and water. Check the temperature and humidity level.

  • DS1820 thermometer
  • Thermal sensor DS1923
  • Soway T118 temperature and humidity sensor

Set up a tire pressure monitoring system

Too low or too high pressure will destroy the tire. It depends on the tires how well the car will drive and how much gasoline will it consume. Constant pressure monitoring allows to reduce the tire wear rate, reduce fuel consumption and prevent the accident and alert the driver about the flat tire instantly.

  • Pressure Pro
  • Pressure Pro Pulse
  • TPMS 6-13
  • TM-508

Get basic CAN data rapidly

You’re into an ordinary project and basic CAN data set needed? Use CAN LOG to get standard data quickly. Opt for contactless pulse readers to receive data from external equipment that is not connected to the CAN-bus.

How to make integration on your own?

  1. Make sure that GPS tracking device and the peripheral support required interface: RS 232, RS 485 or CAN
  2. Receive the protocol from the peripheral manufacturer
  3. Explore, what data, in what format, in what frequency you can transfer
  4. Connect the peripheral device to a PC for a check
  5. Program the tracker with the Easy Logic tool in Configurator program
  6. Use Script block and follow the instruction
